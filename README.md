# wildfire-flux-explorer
Interactive hand-gesture controlled 3D explorer for wildfire impacts on atmosphere-biosphere fluxes (pre/during/post-fire SH, LH, ET, GPP, VPD, AOD) over Indian forests like Similipal. Inspired by takeapart.app, using MediaPipe Hands + Three.js. PhD research visualization by M.S. Shyam Sunder.
